# Setup Multi-Agent Project

Set up the current project in MCP Agent Mail with customizable agent personas.

## Persona Definitions

Read persona definitions from `~/.claude/agent-personas.md`. This file contains:
- Built-in personas (Frontend, Backend, Reviewer, Tester, DevOps, Architect, Docs, Security)
- Custom personas the user has added
- File patterns and restrictions for each

## Instructions

### Step 1: Check Prerequisites

1. Get the current working directory with `pwd` - this is your project path
2. Verify MCP Agent Mail server is running:
   ```bash
   curl -s http://127.0.0.1:8765/mcp/ -X POST -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"ping","params":{}}' 2>/dev/null || echo "NOT_RUNNING"
   ```
   If not running, tell user to run `am` in a separate terminal first and wait for them to confirm.

### Step 2: Ask User Which Agents They Want

1. Read `~/.claude/agent-personas.md` to get all available personas (built-in + custom)
2. Present them to the user with the AskUserQuestion tool (multiSelect: true)

**Available Personas** (from ~/.claude/agent-personas.md):
- Frontend, Backend, Reviewer, Tester, DevOps, Architect, Docs, Security
- Plus any custom personas the user has defined

Ask: "Which agent personas do you want for this project?"

Options should include all personas from the file plus "Custom (define a new one)".

### Step 3: Choose AI Backend for Each Persona

For each selected persona, ask which AI backend to use. Use AskUserQuestion.

**Available backends:**
- `claude` - Claude Code (default for most)
- `codex` - OpenAI Codex CLI (recommended for Reviewer)
- `gemini` - Google Gemini CLI
- `aider` - Aider coding assistant

Example question: "Which AI backend for the Reviewer agent?"
- Options: Claude Code, Codex (Recommended), Gemini, Aider

Note: The personas file may have a "Recommended backend" - use that as the default/first option.

### Step 4: Handle Custom Personas

If user selected "Custom", ask them to describe:
- Role name (e.g., "DataScience", "Mobile", "ML")
- Description (what this agent does)
- Any restrictions (e.g., "never modifies production configs")
- Which AI backend to use

Repeat for each custom persona they want to add.

### Step 5: Confirm Agent List

Show the user the final list of agents that will be created and ask for confirmation:
```
You've selected these agents for [project]:

| Role | Backend | Description |
|------|---------|-------------|
| Frontend | claude | UI components, styles |
| Backend | claude | API, server logic |
| Reviewer | codex | Code review only |

Proceed with setup? (yes/no)
```

### Step 6: Register Project and Agents

1. Read bearer token from `~/mcp_agent_mail/.env` (extract HTTP_BEARER_TOKEN)

2. Register the project:
   ```bash
   curl -s -X POST http://127.0.0.1:8765/mcp/ \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"ensure_project","arguments":{"human_key":"<PROJECT_PATH>"}}}'
   ```

3. For each selected persona, register an agent with the appropriate backend:

   **For Claude Code agents:**
   ```bash
   curl -s -X POST http://127.0.0.1:8765/mcp/ \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"register_agent","arguments":{"project_key":"<PROJECT_PATH>","program":"claude-code","model":"claude-opus-4-5","task_description":"[ROLE] Description here"}}}'
   ```

   **For Codex agents:**
   ```bash
   curl -s -X POST http://127.0.0.1:8765/mcp/ \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"register_agent","arguments":{"project_key":"<PROJECT_PATH>","program":"codex-cli","model":"gpt-4","task_description":"[ROLE] Description here"}}}'
   ```

   **For Gemini agents:**
   ```bash
   curl -s -X POST http://127.0.0.1:8765/mcp/ \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"register_agent","arguments":{"project_key":"<PROJECT_PATH>","program":"gemini-cli","model":"gemini-2","task_description":"[ROLE] Description here"}}}'
   ```

   Capture the auto-generated name from each response.

### Step 7: Create Mapping File

Save `.agent-mail-roles.md` in the project root:

```markdown
# Agent Mail Roles for [Project Name]

> Auto-generated by `/setup-agents` on [date]

## Active Agents

| Role | Agent Name | Backend | Description | Restrictions |
|------|------------|---------|-------------|--------------|
| Frontend | [name] | claude | UI components, styles | - |
| Backend | [name] | claude | API, data handling | - |
| Reviewer | [name] | codex | Code review | Never writes code |

## How to Use

### Starting Agents
Run `./start-agents.sh` to launch all agents in separate terminals.

### Communication
- Agents coordinate via MCP Agent Mail
- Check inbox: agents call `fetch_inbox`
- Send message: agents call `send_message`
- Reserve files: agents call `file_reservation_paths` before editing

### Web UI
View all messages: http://127.0.0.1:8765/mail
```

### Step 8: Create Launcher Script

Create `./start-agents.sh` in the project root:

```bash
#!/bin/bash
# Auto-generated by /setup-agents on [date]
# Launch all agents for [project]

PROJECT="<PROJECT_PATH>"

# Check if Agent Mail server is running
if ! curl -s http://127.0.0.1:8765/mcp/ > /dev/null 2>&1; then
    echo "Agent Mail server not running. Start it with: am"
    exit 1
fi

echo "Launching agents for: $PROJECT"

# Define the system prompt template
make_prompt() {
    local NAME="$1"
    local ROLE="$2"
    local DESC="$3"
    local RESTRICT="$4"
    local OTHERS="$5"

    echo "You are $NAME, the $ROLE agent for this project.

Your responsibilities:
- $DESC

Rules:
- Reserve files via Agent Mail before editing
- Check your inbox regularly for messages
- Coordinate with other agents
- $RESTRICT

Other agents in this project:
$OTHERS"
}

# Launch Claude Code agent (example for Frontend)
wt.exe -w 0 new-tab --title "[ROLE] - [NAME] (claude)" wsl.exe -- bash -c "
cd '$PROJECT'
claude --system-prompt '\$(make_prompt \"[NAME]\" \"[ROLE]\" \"[DESC]\" \"[RESTRICT]\" \"[OTHERS]\")'
exec bash"

# Launch Codex agent (example for Reviewer)
wt.exe -w 0 new-tab --title "[ROLE] - [NAME] (codex)" wsl.exe -- bash -c "
cd '$PROJECT'
codex --full-auto --system-prompt '\$(make_prompt \"[NAME]\" \"[ROLE]\" \"[DESC]\" \"[RESTRICT]\" \"[OTHERS]\")'
exec bash"

# Launch Gemini agent (if any)
# wt.exe -w 0 new-tab --title "[ROLE] - [NAME] (gemini)" wsl.exe -- bash -c "
# cd '$PROJECT'
# gemini --system-prompt '...'
# exec bash"
```

**Backend-specific CLI flags:**
- `claude` → `claude --system-prompt "..."`
- `codex` → `codex --full-auto --system-prompt "..."`
- `gemini` → `gemini --system-prompt "..."`
- `aider` → `aider --message "..."`

Make it executable: `chmod +x ./start-agents.sh`
